# Receptie Paste Label

O pagină cu un singur buton `PASTE`. Citește codul text din clipboard și îl imprimă ca etichetă QR folosind același protocol Niimbot, aceeași dimensiune și același aranjament ca aplicația Receptie. Nu citește camera, nu modifică stocul și nu apelează servicii de business.

Deschide pagina prin HTTPS într-un browser cu Web Bluetooth. La prima folosire, butonul poate cere permisiunea pentru clipboard și alegerea imprimantei; după acordarea permisiunii, imprimanta autorizată este reconectată automat când browserul oferă această funcție.
